🎯 Descripción

Andamiaje Pedagógico es una herramienta web que utiliza inteligencia artificial para crear experiencias de aprendizaje estructuradas y progresivas. Basada en principios de pedagogía constructivista, genera andamiajes que retiran el apoyo gradualmente conforme el estudiante demuestra dominio.

¿Qué es un andamiaje pedagógico?
Un andamiaje es un apoyo temporal que guía al estudiante desde tareas que no puede resolver solo hacia la autonomía completa. A medida que gana confianza y comprensión, el apoyo se retira progresivamente.

📖 Áreas de Aprendizaje

La plataforma soporta 7 áreas de aprendizaje, cada una con su propio enfoque pedagógico:

1️⃣ Matemáticas y Ciencias

Enfoque: Aprendizaje progresivo y resolución de problemas

Énfasis en conceptos, procedimientos y razonamiento lógico.

2️⃣ Lectura, Escritura y Comunicación

Enfoque: Construcción de textos y argumentos propios

Énfasis en comprensión, análisis, redacción y pensamiento crítico.

3️⃣ Ingeniería y Programación

Enfoque: Diseño, implementación y validación de soluciones

Énfasis en problemas técnicos, código funcional y depuración.

4️⃣ Aprendizaje Colaborativo

Enfoque: Resolución grupal de problemas

Énfasis en argumentación, colaboración y construcción colectiva.

5️⃣ Educación Digital e IA

Enfoque: Uso de herramientas digitales e IA con pensamiento crítico

Énfasis en autonomía intelectual y evaluación de resultados.

6️⃣ Educación Inclusiva

Enfoque: Accesibilidad y enseñanza diferenciada

Énfasis en apoyos ajustados, ritmo personalizado y autonomía.

7️⃣ Formación Profesional

Enfoque: Competencias prácticas y experienciales

Énfasis en desempeño, seguridad y transferencia a situaciones reales.

📊 Niveles de Andamiaje

Cada andamiaje generado incluye 4 niveles progresivos:

Yo lo hago — Modelado
Presenta un problema resuelto completo. Explica cada paso y justifica las decisiones.
Lo hacemos juntos — Práctica Guiada
El estudiante resuelve paso a paso con guía del tutor. Retroalimentación inmediata ante errores.
Tú, con ayuda — Práctica Asistida
El estudiante resuelve el problema completo. Pistas progresivas según necesidad.
Tú lo haces solo — Práctica Autónoma
5 retos sin apoyo para transferencia del aprendizaje. Evaluación de generalización.

🚀 Características

Generación Dinámica de Andamiajes

  • Selecciona un área de aprendizaje
  • Escribe un tema específico
  • La IA genera un andamiaje completo con 4 niveles

Interfaz Interactiva

  • Práctica interactiva integrada con fracciones
  • Visualización gráfica de operaciones
  • Andamiaje adaptativo que se retira automáticamente

Descarga de Andamiajes

  • Exporta andamiajes como archivos HTML independientes
  • Comparte con estudiantes o colegas
  • Funciona sin conexión una vez descargado

📝 Cómo Usar

Generar un Andamiaje

Selecciona el área de aprendizaje
Elige de la lista desplegable. El enunciado cambiará automáticamente.
Escribe el tema
Ejemplo: "Derivadas de funciones polinómicas" o usa los ejemplos sugeridos.
Configura el proveedor de IA
Selecciona proveedor, modelo y añade tu API Key si es necesaria.
Genera el andamiaje
Haz clic en "✨ Generar andamiaje" y espera 1-2 minutos.
Explora el andamiaje
Navega por los 4 niveles, resuelve ejercicios y descarga si deseas compartir.

Práctica Interactiva con Fracciones

En la sección 2, practica operaciones con fracciones:

  1. Selecciona la operación (+, −, ×, ÷)
  2. Elige el nivel de apoyo (1-4)
  3. Resuelve los retos
  4. El andamiaje se retira automáticamente al avanzar

⚙️ Personalización

Modificar System Prompts

Edita el archivo andamiaje.md para personalizar los enfoques pedagógicos de cada área. Cada sección inicia con:

# SYSTEM PROMPT — Tutor de andamiaje para [área]

Agregar Proveedores de IA

En el archivo index.html, modifica el objeto PROVIDERS:

const PROVIDERS = {
  tuProveedor: {
    name: 'Nombre del Proveedor',
    url: 'https://api.ejemplo.com/chat',
    model: 'modelo-por-defecto',
    placeholder: 'Formato de clave',
    keyUrl: 'https://ejemplo.com/keys'
  }
};

🐛 Solución de Problemas

❌ "No se pudo generar el andamiaje"

  • Verifica que la API Key sea válida
  • Intenta con otro proveedor de IA
  • Revisa tu conexión a internet

❌ "El andamiaje ignora el área seleccionada"

  • Usa OpenRouter como proveedor (Red Descartes tiene limitaciones)
  • Algunos modelos responden mejor que otros
  • Intenta con un modelo diferente

❌ "La práctica de fracciones no funciona"

  • Limpia el caché del navegador (Ctrl+Shift+R)
  • Asegúrate de que JavaScript esté habilitado
  • Intenta en otro navegador

🎓 Principios Pedagógicos

Andamiaje Progresivo

El apoyo se retira gradualmente conforme aumenta la autonomía del estudiante.

Adaptación

El andamiaje se ajusta al desempeño: respuestas correctas reducen el apoyo, errores repetidos refuerzan el apoyo.

Transferencia

Los niveles 3 y 4 incluyen problemas nuevos que requieren aplicar el conocimiento a situaciones diferentes.

Retroalimentación Específica

Cada error recibe una explicación conceptual, no solo la respuesta correcta.

Evaluación Formativa

Se valora exactitud, procedimiento, comprensión conceptual y autonomía.
