Generador de Puzle Arrastrable — Guía de uso para adultos mayores

Esta aplicación permite crear un rompecabezas (puzle) a partir de una imagen generada por inteligencia artificial y armarlo arrastrando las piezas con el mouse. Fue diseñada para usarse desde un computador, con botones grandes y pasos simples.

¿Para qué sirve?

Es un ejercicio de estimulación cognitiva. Armar rompecabezas ayuda a ejercitar la memoria, la atención y la coordinación visual-manual, habilidades especialmente valiosas para personas mayores.

Cómo usarla, paso a paso

  1. Abrir la aplicación Haga doble clic sobre el archivo index.html. Se abrirá en su navegador de internet (Chrome, Edge, Firefox, etc.). No necesita conexión a una página web especial, solo tener internet activo para generar la imagen.

  2. Elegir un tema En la parte de arriba encontrará un cuadro de texto que dice "Tema para la imagen...". Allí puede escribir, por ejemplo: "un gato", "flores de primavera", "un paisaje de montaña".

  3. Elegir un estilo (opcional) Al lado hay una lista desplegable con estilos como Realista, Acuarela, Cartoon, etc. Si no está segura o seguro de cuál elegir, puede dejarlo así o escoger "Realista".

  4. Generar la imagen Haga clic en el botón "Generar Imagen". Espere unos segundos mientras aparece el mensaje "Cargando imagen...". Cuando la imagen aparezca, ya está lista para convertirse en rompecabezas.

  5. Elegir la dificultad del puzle Debajo de la imagen aparecerán varios botones:

    • Puzle 2x2 (Test): el más fácil, ideal para practicar cómo funciona.
    • Puzle 3x3: dificultad baja.
    • Puzle 4x4: dificultad media.
    • Puzle 5x5: dificultad alta.

    Se recomienda comenzar con el 2x2 o el 3x3 si es la primera vez que se usa la aplicación.

  6. Armar el rompecabezas Las piezas aparecerán del lado izquierdo, en una zona llamada "Piezas Sueltas". Para armar el puzle:

    • Haga clic sobre una pieza y, sin soltar el botón del mouse, arrástrela hasta el tablero de la derecha.
    • Suelte el botón cuando la pieza esté en el lugar correcto; si está cerca de su posición, se acomodará sola (esto se llama "imantado" o snap).
    • Repita este paso con cada pieza hasta completar la imagen.

  7. Mensaje de felicitación Cuando todas las piezas queden en su lugar, aparecerá un mensaje indicando que el rompecabezas se ha completado correctamente.

  8. Descargar el rompecabezas (opcional) Si desea guardar este rompecabezas para jugarlo después o compartirlo, use el botón "Descargar Puzle". Esto crea un archivo que se puede abrir nuevamente sin necesidad de generar otra imagen.

Recomendaciones

  • Use el mouse con calma; no es necesario hacer clics rápidos.
  • Si una pieza no encaja, puede volver a intentarlo tantas veces como sea necesario; no hay límite de tiempo ni penalización.
  • Si algo no funciona, cierre la ventana del navegador y vuelva a abrir el archivo index.html.
  • Se recomienda el acompañamiento de un familiar o cuidador la primera vez que se use la aplicación.
