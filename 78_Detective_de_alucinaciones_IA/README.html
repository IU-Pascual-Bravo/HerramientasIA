Detective de Alucinaciones IA

Aplicación web educativa para crear cuestionarios con ayuda de modelos de inteligencia artificial. Cada pregunta presenta cuatro afirmaciones: tres verdaderas y una falsa o «alucinación»; el jugador debe identificar la falsa y luego puede consultar la explicación.

Funciones

  • Genera categorías de trivia escolar o permite escribir un tema propio.
  • Ofrece varios proveedores y modelos de IA.
  • Permite configurar dificultad fácil, media o difícil y entre 4 y 15 preguntas (5 por defecto).
  • Baraja las afirmaciones, muestra explicaciones y lleva puntuación, racha y precisión.
  • Descarga un cuestionario como HTML independiente y jugable sin conexión.
  • Guarda el proveedor preferido y las claves API en el almacenamiento local del navegador.

Archivos y requisitos

  • index.html: aplicación completa, con estilos, lógica e interfaz.
  • logoPB1.png y logo_escuela.png: imágenes del encabezado.
  • Modelo_logos/: aplicación de referencia para los logos; no es necesaria para ejecutar la app principal.

No se requieren paquetes, compilación ni un servidor backend propio. Se necesita un navegador moderno con JavaScript habilitado. La generación de temas y preguntas requiere Internet y un proveedor de IA; Red Descartes no requiere API key.

La interfaz carga Google Fonts desde Internet y utiliza fuentes alternativas si el servicio no está disponible.

Ejecución

Se recomienda servir la carpeta con un servidor HTTP local, ya que algunos navegadores restringen las solicitudes de red desde direcciones file://.

En Windows, abre una terminal en la carpeta del proyecto:

py -m http.server 8000

En macOS o Linux:

python3 -m http.server 8000

Abre http://localhost:8000. También es posible abrir index.html directamente, aunque las solicitudes a proveedores externos pueden estar limitadas por el navegador.

Configurar un proveedor

  1. En Proveedor y API Key, selecciona el servicio de IA.
  2. Si requiere clave, créala en el sitio oficial del proveedor e introdúcela en el campo. El botón Obtener API Key abre el sitio correspondiente cuando está disponible.
  3. Pulsa Validar para comprobar la clave. También puedes intentar usarla sin validación previa.
  4. Elige un modelo en Modelo IA y comprueba que corresponda al proveedor seleccionado.

Proveedores incluidos: Red Descartes (sin clave), Google AI Studio, Mistral AI, Cohere, Groq, Pollinations AI, OpenRouter (selección inicial) y DeepSeek. La lista de modelos está definida en index.html; los servicios pueden cambiar sus catálogos y disponibilidad.

Crear y jugar

  1. Selecciona una categoría sugerida o escribe un tema propio. Pulsa Nuevos Temas para generar otras categorías.
  2. Configura la dificultad y la cantidad de preguntas. El número se ajusta al rango permitido de 4 a 15.
  3. En cada pregunta, identifica cuál de las cuatro afirmaciones es falsa.
  4. Lee el resultado y la explicación, y avanza a la siguiente pregunta.
  5. Al terminar, consulta los aciertos y la precisión. Elige Crear Nuevo para iniciar otra partida o Descargar este Cuestionario (Clon) para exportar la partida.

El clon descargado contiene las preguntas ya generadas, no contiene una clave API y puede jugarse sin conexión. No genera preguntas nuevas.

Privacidad y uso responsable

  • Las claves se guardan en localStorage y no están cifradas. Evita guardar claves en perfiles compartidos o dispositivos públicos. El botón Limpiar elimina la clave del proveedor actual.
  • Los temas y prompts se envían directamente al proveedor seleccionado. Revisa sus condiciones de privacidad, límites y posibles costos.
  • La IA puede generar errores. Verifica las afirmaciones y explicaciones antes de utilizarlas con fines académicos.
  • No incluyas claves API ni información sensible en los temas que escribas.

Solución de problemas

  • No aparecen categorías: comprueba la conexión, el proveedor, la clave y el modelo; vuelve a pulsar Nuevos Temas.
  • No se valida la clave: confirma que pertenezca al proveedor seleccionado, que esté activa y que el servicio permita solicitudes desde el navegador. Las restricciones de red o CORS dependen del proveedor.
  • No se genera una pregunta: revisa el mensaje de estado e inténtalo de nuevo. La app puede reintentar hasta tres veces si la respuesta no tiene el formato esperado.
  • El modelo no está disponible: selecciona otro modelo ofrecido por ese proveedor.
  • No se recuerda la configuración: verifica que el navegador permita almacenamiento local y que no se haya borrado el almacenamiento del sitio.
