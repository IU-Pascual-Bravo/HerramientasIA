100 estilos de generación de imágenes

Aplicación web que permite generar imágenes con IA usando 100 estilos visuales organizados en 10 categorías, utilizando la API de Pollinations.ai.

Categorías

  1. Fotografía y estilos de cámara
  2. Cine y películas
  3. Ilustración y arte tradicional
  4. Diseño y estilos gráficos
  5. Arte 3D, isométrico y videojuegos
  6. Retro y vintage
  7. Futurista y ciencia ficción
  8. Bellas Artes e Historia
  9. Cultura pop y estética de internet
  10. Técnicas experimentales y mixtas

Cada categoría incluye 10 estilos únicos con descripciones detalladas para guiar la generación.

Funcionalidades

  • Selector de categoría: elige entre 10 categorías temáticas
  • Tema sugerido: cada categoría propone un tema predeterminado, con opción a personalizado
  • Estilos dinámicos: los 10 estilos se actualizan automáticamente según la categoría seleccionada
  • Relación de aspecto: 16:9, 1:1, 9:16, 4:3 y 3:4
  • Galería: las imágenes generadas se acumulan en una galería con scroll horizontal
  • Descargas:
    • Imagen individual (PNG)
    • ZIP con todas las imágenes
    • HTML interactivo con transiciones animadas
    • Galería HTML responsive
  • Copiar JSON prompting: copia el prompt completo como JSON
  • Soporte multilingüe: español, inglés y francés
  • Pan & Zoom: arrastrar y escalar la imagen generada

Tecnologías

  • HTML5 / CSS3 / JavaScript vanilla
  • API de Pollinations.ai (generación de imágenes)
  • JSZip (empaquetado ZIP)
  • DeepSeek V4
